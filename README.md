# 💸 BlacRate Pro
**A Professional Crypto-to-Naira Rate & Profit Calculator.**

BlacRate Pro is a high-performance, mobile-first Web App (PWA) designed for traders to calculate accurate exchange rates, track profit margins per dollar, and generate professional trade quotes instantly.

## 🚀 Key Features
* **Live Market Rates:** Real-time fetching of BTC, ETH, SOL, and USDT prices via CoinGecko API.
* **Dynamic Profit Logic:** Calculate your commission automatically based on a custom Naira margin per USD.
* **Offline Mode:** Powered by Service Workers to ensure the app works even in low-connectivity areas.
* **Bento UI Design:** A clean, high-contrast dark interface optimized for OLED screens (like the Samsung A14).
* **Trade History:** Localized storage to keep track of your most recent 5 calculations.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), Modern JavaScript (ES6+).
* **PWA:** Service Workers, Web App Manifest.
* **APIs:** CoinGecko API (Crypto), ExchangeRate-API (Official NGN).

## 📲 Installation
Since this is a **Progressive Web App**, you can install it on your device:
1. Open the [ https://blaconchain.github.io/blacrate-pro/ ] in Chrome.
2. Tap the **3-dot menu** or the **Install App** icon in the address bar.
3. Access it directly from your home screen.

## 📝 Usage
1. Select your asset (e.g., USDT or BTC).
2. Input the crypto amount.
3. Set your **Profit (Per $1)**—the app calculates the total commission automatically.
4. Click **Copy & Save** to format a WhatsApp-ready quote for your client.
